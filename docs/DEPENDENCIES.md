# Dependency verification

Release preparation ran `npm audit --json` and `npm audit --omit=dev` against the actual lockfile on 2026-10-09. The runtime-only audit reported **zero vulnerabilities**. The complete development tree initially reported nine, including two critical findings associated with Vitest's worker pool. Vitest was upgraded to 4.1.11 and pinned through a root override because Angular's build package also includes an optional older Vitest dependency. Backend tests, both builds and Angular browser tests passed after this change.

The full audit now reports **six high development dependency findings** through Karma/chokidar/braces. The underlying [braces advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) covers the currently published 3.0.3 release; there is no patched braces version available from the registry at this verification. The audit suggests downgrading major test/build packages, which would invalidate the selected Angular setup. Those downgrades were not applied. This remaining issue is explicitly recorded rather than describing the full dependency tree as clean. Runtime API dependencies and compiled browser bundles do not include Karma's file watcher.

Karma is used locally and in CI with repository-owned test paths. Keep the test server on a trusted development machine and review untrusted repository changes before running them. The selected fix addresses the [Vitest mocker advisory](https://github.com/advisories/GHSA-82fw-gwwq-j7x9) and removes the affected [Tinypool dependency](https://github.com/advisories/GHSA-85c8-ppgw-ccpr) from this tree. Re-run both audit commands when updating dependencies; these results are not a guarantee against future advisories.
